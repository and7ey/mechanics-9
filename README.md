# Механика. Инженеры будущего. 9 класс

Интерактивная 3D-книга по механике для 9 класса. Каждый параграф — разворот: слева текст, формула и вопросы, справа рисунок, который поднимается со страницы и с которым можно взаимодействовать.

Первая версия: § 23 «Сила упругости. Закон Гука», § 24 «Вес тела», § 25 «Сила трения», плюс обложка-содержание и итоговый разворот с викториной.

**Демо:** https://and7ey.github.io/mechanics-9/

## Что внутри

- **Пять разворотов** с перелистыванием страниц и «подъёмом» рисунка со страницы.
- **Три интерактивные модели:**
  - пружина с грузами: закон Гука, живое удлинение, график F(Δl), предел пропорциональности;
  - тело на весах в лифте: `P = m(g ± a)`, перегрузка и невесомость;
  - брусок на поверхности: трение покоя и скольжения, `F = μN`, поверхности и катки.
- **Клапан «Почему?»** — 3D-карточка, под которой напечатан ответ.
- **Вопрос «Подумайте»**, **испытание** со штампом, живые числа на полях.
- **Оглавление всего учебника** — § 1–61, готовые параграфы отмечены и открываются.
- **Текстовая версия** (кнопка «Т») и скрытый текст для скринридеров, управление с клавиатуры.
- **Звук** (WebAudio, синтез): шелест страницы, перо, клапан, штамп — отключается кнопкой.

## Стек

Vite 8, TypeScript, three.js. Без фреймворка: книга и страницы — Canvas2D-текстуры на 3D-плоскостях, интерфейс — небольшой DOM-слой.

```
src/
  core/      книга, страницы, перелистывание, камера, ввод, прогресс, звук
  ink/       бумага, штриховка, шрифты, формулы, графики, 3D-примитивы
  layout/    вёрстка левой и правой страницы, обложка, итог
  content/   оглавление (§1–61) и тексты параграфов
  scenes/    пружина, лифт, трение
  text/      текстовая версия и панель
  physics.ts чистые формулы (покрыты тестами)
```

## Команды

```sh
npm install
npm run dev        # http://localhost:5173/mechanics-9/
npm test           # формулы и валидация контента
npm run build      # tsc + vite
npm run deploy     # сборка и публикация на GitHub Pages
```

## Как добавить параграф

1. Создайте `src/content/lessons/NN.ts` по образцу соседних: объяснение, уравнение, ключевые слова, вопрос, клапан, испытание, переключатели, `scene`.
2. Добавьте урок в `LESSONS` в `src/content/book.ts`.
3. Если нужна новая модель — реализуйте `Scene` в `src/scenes/` и подключите в `ensureScene`.
4. Отметьте номер готовым (это происходит автоматически через `LESSONS`) и запустите `npm test`.

Оглавление уже содержит все §1–61, поэтому новая тема сразу появится на месте.

Код и графика — оригинальные. Шрифты Source Serif 4 и Caveat распространяются по лицензии SIL OFL.
